# Mermaid 零基础中文教程

> 一套面向**完全零基础读者**的简体中文教程，带你从「什么是 Mermaid」一路学到「用文本画出 30 多种图、并排查常见故障」。本教程基于 `D:\mermaid-develop`（Mermaid 11.x 源码仓库）编写，所有内容均可在仓库中找到真实对应。

## 这套教程讲什么

Mermaid 是一个用 JavaScript 写成的开源库：你写一段「类 Markdown 的文本」描述图表，它自动帮你渲染成 SVG 图片。它解决了「文档里的图容易过时、难维护」的老大难问题——因为图是文本，可以放进版本控制、可以 code review、改起来只动几行字。

本教程不要求你懂命令行、不要求你会编程。所有「下载、安装、运行」的操作，都写成「对智能体说的话」，你只要原样发给智能体（例如 hermes agent）即可。

## 适用读者

- 想快速用文本画流程图、时序图、思维导图的人；
- 不太熟悉命令行、Git、前端工程，但希望把 Mermaid 用起来的非程序员；
- 想把 Mermaid 仓库跑起来、看看各种图长什么样、甚至参与贡献的开发者（第 3、5、12 章为你准备）；
- 已经会用一点 Mermaid，但想系统搞懂配置、主题、API 的人。

## 几个重要约定（避免踩坑）

- 本教程所说版本均为 **mermaid 11.x**（仓库根目录那个 `10.2.4` 是整个大仓库的元版本号，不代表发布的库版本）。
- 自动渲染认的是 **`class="mermaid"`** 这个 CSS 类（`<pre>` 或 `<div>` 都可以），**不是** `<mermaid>` 标签。
- 所谓「浏览器 standalone 独立版」对应的是 `mermaid.min.js`（IIFE 全局构建），**不存在** `mermaid.standalone.js` 这个文件。
- Mermaid 的解析器有两套：约 12 种图用 **Langium**，约 18 种图用 **Jison**，不要只记其中一种。
- 在线练手最方便：打开官方 Live Editor `https://mermaid.live/`，或本地 `pnpm dev` 后访问 `http://localhost:9000/dev/`。

祝画图愉快！遇到任何问题，先看第 12 章，或把报错原样发给你的智能体。
